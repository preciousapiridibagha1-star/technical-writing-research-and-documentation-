# Before-and-After Documentation Improvement

**Example type:** Documentation editing sample based on the Vantage Automata project concept.  
**Source:** The project's original short description and the current Vantage Automata portfolio overview.  
**Status:** The "before" text below is a simplified example created to show the documentation problem. It is not presented as a quotation from an old published file.

## Before

> Vantage Automata is an AI automation platform that helps users complete tasks automatically. It uses AI to understand instructions and perform actions.

## What is missing?

A reader cannot tell:
- Whether the product exists and works.
- What happens before an action is taken.
- Whether a person can approve or reject the action.
- What kind of tasks are supported.
- Whether the system has been tested.

The wording also makes the project sound like a finished product, which is not supported by the available evidence.

## After

> Vantage Automata is a self-directed AI task-system concept. A person describes a task, AI prepares a proposed action, and the person reviews that proposal before it can proceed. The current portfolio documents the problem, proposed workflow, requirements, architecture and test plan. An earlier prototype was explored, but its source code is no longer available for inspection. A working MVP and successful tests are therefore not claimed.

## What changed?

1. **The project status is clear.** The reader knows this is a concept, not a verified product.
2. **The main workflow is explained.** The person gives an instruction, AI prepares a proposal, and the person reviews it.
3. **Human control is visible.** The reader understands that approval is part of the design.
4. **The evidence limit is honest.** The text does not claim that the old prototype still works.
5. **The work is easier to assess.** A reviewer can see what has been documented and what remains to be built.

## Writing lesson

A good project description should answer three simple questions: What is it? How is it meant to work? What evidence do we actually have? Clear writing is more valuable than making a project sound bigger than it is.
