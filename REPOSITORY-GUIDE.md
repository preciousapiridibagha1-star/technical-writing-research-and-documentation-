## 1. Recommended reading paths

1. [Projects Index](projects/README.md).

## 9. Navigation and maintenance rules

- Every substantial project folder should have a `README.md` that explains purpose, current status, contents and next steps.
- The root README is the public landing page; it should link to indexes, not reproduce every project document.
- Folder-level indexes should link to their detailed documents using relative paths.
- Keep one authoritative version of each active document; label superseded versions rather than silently duplicating them.
- Preserve project folders and evidence history unless there is a clear, reviewed reason to change them.
- Update status pages when the evidence changes, not merely when plans change.
- Verify links and claims before marking a section complete.
- Keep all portfolio work on the default `main` branch unless a separate review branch is intentionally used.
