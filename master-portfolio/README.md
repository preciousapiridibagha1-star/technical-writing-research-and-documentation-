## How to read the evidence

Each capability page sets out the question or problem, work produced, a before-and-after improvement, what the evidence demonstrates, and what remains unverified.

**Evidence rule:** a specification is not an implementation; a passing unit test is not a security audit; desk research is not hands-on testing; a policy proposal is not proof of compliance; and a proposed architecture is not a deployed system.
