## Main-branch history and branch hygiene

The default branch is `main`. Earlier audits compared several long-lived branches with main and recorded them as divergent historical branches. They were not merged wholesale because they contain older or overlapping versions of portfolio and project material.

No branch should be merged solely to make the branch list look tidy. Preserve historical branches unless there is a specific reason to remove them. Recover a missing change only after comparing it with the current main branch and verifying that it is genuinely absent.

The current public portfolio content is linked from `main`; a branch name is not a substitute for a link. The [Repository Guide](REPOSITORY-GUIDE.md) is the authoritative file-location map.

## Evidence standard

- Desk research is not field research or a systematic review.
- A fictional case study is not an audit of a real organisation.
- A concept or architecture diagram is not a deployed system.
- A local prototype is not a production integration.
- Passing unit tests do not constitute a security audit.
- A submitted pull request is not a merged contribution.
- Public organisational statements are attributed, not treated as independent verification.
- No partnership, endorsement, consultation, deployment or measured impact is claimed without evidence.
