# Project 3: Usage Guide — General Workflow for a Cloud AI Assistant

**Document type:** Illustrative workflow guide, not vendor-specific instructions.  
**Audience:** A first-time user who has access to a cloud AI assistant.  
**Goal:** Complete a low-risk drafting or summarisation task while checking the result.

> Product interfaces, account requirements, file handling and available features vary. Follow the named provider's current help centre for exact screen-by-screen instructions.

## Before you begin

- Use an account and device you are authorised to use.
- Check the provider's privacy and data-use terms.
- Do not enter passwords, payment details, confidential client records or sensitive personal information unless the service and your organisation explicitly permit it.
- Prepare the source text you are allowed to share.
- Decide what a useful result should look like.

## Workflow

### 1. Open the service

Use the provider's official website or official app-store listing. Sign in using the method supported by that provider. Check that you are in the correct account and workspace before entering information.

**Expected result:** The assistant's input area or equivalent interaction screen is available.

### 2. Write a bounded instruction

State the task, the context, the source material and the desired format. For example:

> Summarise the notes below in five bullet points. Use only information in the notes. Mark any missing dates or unclear facts as “not stated”. Do not invent names, figures or actions.

Avoid asking the assistant to make decisions that require authority you have not granted.

### 3. Review the response

Compare the output with the original material. Check names, dates, quantities, quotations, calculations and any statement that could affect a person or business. Ask for a correction where an error is found, but verify the revised answer again.

### 4. Decide whether to use or export it

Use the provider's documented save, copy or export option only after reviewing the output. Check the destination and sharing permissions before sending or publishing it.

### 5. Stop when the tool is uncertain

If the result is unsupported, contradictory or incomplete, do not present it as fact. Return to the original source, consult a reliable reference or ask a qualified person.

## Common problems and safe responses

| Problem | Safe response |
|---|---|
| The answer invents a fact or source | Remove the claim and verify from the original source |
| The assistant misunderstands the task | Restate the task and provide relevant, non-sensitive context |
| An uploaded file is not recognised | Check provider-supported formats and file-size limits |
| The interface or feature is missing | Consult the provider's current help documentation and plan limits |
| The response includes sensitive information | Stop sharing; follow the provider and organisation's incident/reporting process |

## Completion check

Before using the output, confirm that it answers the intended task, preserves the source meaning, contains no unsupported facts, excludes unauthorised information and has been checked by a responsible person.

## Limitations

This guide does not describe a tested product interface. No live walkthrough, usability test or feature verification was conducted. It is a generic workflow sample; vendor-specific instructions require direct inspection of a named product and its current documentation.

**Portfolio purpose:** Demonstrates task-based instructional writing, expected-result thinking, safety notes and troubleshooting structure.
