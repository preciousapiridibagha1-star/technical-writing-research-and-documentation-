## How the projects relate

The projects share an evidence-led approach to technology problems, but they are **separate projects with different purposes**:

- **Vantage Automata** focuses on explicit human approval before a bounded action.
- **Jarvis AI** explores a broader business operating ecosystem and remains a concept.
- **Organisational Intelligence Platform** explores programme data, monitoring and reporting for organisations.
- **MindCommons AI** explores traceability of community-authorised data use and obligations in a specific research-host context.
- **Architecture & Implementation** is a shared explanatory guide, not a separate software product.
- **Cloud Infrastructure & Open Source** contains technical research and overview samples.

Do not imply that these systems are one product, that one has been integrated into another, or that concept documents prove deployment.

## Project reading order

For each project:
1. Read its folder-level `README.md`.
2. Read the problem, scope or product-definition document.
3. Read architecture and workflow documents.
4. Inspect implementation and tests only where they exist.
5. Check the stated limitations before drawing conclusions.
